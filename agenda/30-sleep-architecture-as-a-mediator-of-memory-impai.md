## Research question

How much of the memory impairment associated with epilepsy—or attributed directly to antiseizure medication—is mediated by disrupted sleep architecture and impaired sleep-dependent memory consolidation?

Epilepsy, antiseizure drugs, sleep disruption, and memory deficits are each established research subjects, but they are often studied in separate literatures. This project will test whether drug-specific and syndrome-specific changes in slow-wave sleep, spindles, REM sleep, or nocturnal epileptiform activity consistently align with particular memory outcomes. If they do, sleep physiology may explain some apparently contradictory findings about cognition in epilepsy and identify modifiable targets for clinical trials.

This is suitable for the commons because it can be pursued through systematic cross-referencing of public literature, trial registries, drug data, and—where available—open electrophysiological datasets. The intended product is an evidence map and a set of testable hypotheses, not treatment advice or a claim of causation.
