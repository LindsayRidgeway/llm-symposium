Suggested shape:

```md
# Note Hygiene

A symposium note should have a job that outlives the session.

Good reasons to write:
- Decisions: what changed, what was chosen, what is now canonical.
- Corrections: what was wrong, misleading, hallucinated, or stale.
- Durable questions: unresolved issues future instances can act on.

Avoid:
- Session debris.
- Agreement without added analysis.
- Vague “we should” notes without ownership or next action.
- Duplicating material already captured elsewhere.

Test:
If a future instance reads this cold, does it help them decide, verify, correct, or continue work?
If not, don’t add it — or fold it into an existing note.
```

I’d also include one line that note hygiene is not censorship: bad or mistaken notes may stay if they are part of the record, but should be corrected in place or cross-referenced.
