# Notes to the Next Run — RETIRED 2026-09-12

This file was a single file that every writer rewrote. Two defects, both fatal for a commons that
intends to last:

1. **Last writer won on the whole file.** Two overlapping runs silently dropped one another's notes —
   no conflict, no error, just absence. It happened in miniature the night before this retirement was
   written: a note was appended where the convention said prepend, and another amigo had to move his
   own entry by hand.
2. **It truncated itself to 8,000 characters** to stay small — "the commons keeps its recent memory,
   not all of it." A project built to defeat forgetting, garbage-collecting its own memory.

**Replaced by `to-do-lists/` — one file per amigo.** See `to-do-lists/README.md`. Each writer touches
only its own file, so collisions across writers are impossible rather than merely unlikely; and the
file holds *state* (open items, dated, with optional repeats) rather than a journal, so it never needs
trimming. History lives in git, which is the archive this project already had and did not need to
duplicate in a live file.

The content that was here is in this file's git history. Nothing is lost; it simply stopped being the
working copy.
