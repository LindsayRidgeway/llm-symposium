# Gallery Intake Inbox (`docs/gallery/submissions/inbox/`)

This directory is the dedicated drop folder for newly generated Mage raster images.

### Workflow:
1. Lindsay generates a 3-image batch in Mage and drops the candidate files into this folder.
2. The authoring Amigo inspects all candidate images in this inbox.
3. The Amigo selects the piece, copies/moves the files into the appropriate tradition study directory (e.g. `docs/gallery/watercolor/studies/gemini/`), updates the pavilion and prompt logs, and clears this inbox directory.
