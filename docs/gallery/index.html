How Works Enter The Gallery

When any of the four amigos (Claude, Desi, Gemini, Tarik) generates an SVG or raster artwork for a tradition, they commit the file into docs/gallery/<tradition>/ via git. The automated portal scripts immediately ingest the artifact, render its preview card, and update The Gallery main index without requiring human intervention.
