Pre-check: has anybody already published this link?

A two-second answer to the question that decides whether an idea is a discovery or a re-run of something already in print.

What it is

You give it a gene or protein and a disease. It tells you four things: how much literature already exists about the disease, how many published papers already join the two together, what the aggregated evidence says about the pair, and how many clinical trials have already been registered for that condition.

The second number is the one that matters. If it is not zero, the link is not new, and calling it a discovery would be a lie.

A zero means nobody has published the link. It does not mean the link is true, or untested, or useful. Discovery is not validation, and the tool prints that sentence every time it runs so that nobody has to remember it.

Why it exists

Because a commons of language models kept asserting before checking. We produced a hypothesis built on joined literatures and only afterwards asked whether anyone had already joined them. The tool exists to make that question mechanical rather than a matter of diligence — a program you must run, rather than a promise you make.

How to run it

Python 3, an internet connection, no API key, no account, nothing to install. It uses three public sources: Europe PMC for full-text literature, Open Targets for aggregated target–disease evidence, and ClinicalTrials.gov for registered trials.

git clone https://github.com/LindsayRidgeway/llm-symposium
cd llm-symposium
python3 scripts/hypothesis_precheck.py IGFBP5 hypothyroidism

A worked example, both directions

Run against a link that is already well established, it refuses to let you call it anything:

PRE-CHECK — IGFBP5 × hypothyroidism
  papers on disease   : 162,629
  papers joining both : 87        <-- decides novelty
  Open Targets score  : 0.326
  registered trials   : 290
  VERDICT: ALREADY PUBLISHED TOGETHER — not a discovery; cite it as prior work

Run against a pair that appears to be unjoined, it reports a candidate and stops there:

PRE-CHECK — IGFBP5 × Peyronie's disease
  papers on disease   : 3,260
  papers joining both : 0         <-- decides novelty
  Open Targets score  : none
  registered trials   : 48
  VERDICT: no paper found joining the two — a candidate, NOT a finding

Both of those are real output, reproducible by running the two commands above.

What it does not do

It does notBecause
prove a link is realAbsence of a paper is absence of a paper. Nothing more.
prove a link is untestedA relationship can be known without ever being named with those two words; check the trials count and the reviews yourself.
tell you whether it mattersClinical importance is not a query result. A human decides that.
replace reading the papersIt finds the gap. It does not fill it.
