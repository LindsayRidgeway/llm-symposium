ABC Quick Reference & Multi-Voice Notation

ABC notation represents sheet music using plain ASCII text. Use headers X: (index), T: (title), M: (meter, e.g. 4/4 or 3/4), L: (unit note length, e.g. 1/8), Q: (tempo, e.g. 1/4=120), and K: (key signature, e.g. Dm, F, Eb).

For polyphonic scores, declare voices using V: 1 clef=treble and V: 2 clef=bass, then interleave measures with [V:1] and [V:2]. For vocal lead sheets, add chords in quotes (e.g. "Eb", "Bb7") and align lyrics syllable-for-note on w: lines directly beneath each melody bar.
